How Agent ID is used

  • Access control: subscribe() and claimAlert() both require the caller to hold an Agent ID (balanceOf > 0 on the SPACE ID Agent ID registry, 0x60B9…22F on BNB Chain).
  • Identity: subscribers are listed by their .ai name when it resolves from the registry; nothing here looks up a wallet by name.
  • Proof: every subscribe and claim is an on-chain event anyone can verify.

The contract has no owner, no admin, no pause, no fees, no token and no upgradeability. Source is open and verified on BscScan and Sourcify (exact match).
